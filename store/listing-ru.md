## Detailed description

```
Onliner Price Tracker отслеживает цены товаров на catalog.onliner.by и хранит историю только на вашем устройстве.

Что умеет расширение
• Добавить / снять товар с отслеживания на странице каталога (только по вашему действию)
• Фоновая проверка примерно раз в 3 часа (и кнопка «Check now» в попапе)
• Локальная история цены и небольшой график в окне расширения
• Уведомление Chrome, когда минимальная цена стала ниже предыдущей

Как пользоваться
1. Откройте карточку товара на catalog.onliner.by
2. Нажмите «Watch price» (кнопка справа внизу)
3. Откройте попап расширения — список товаров и графики
4. Разрешите уведомления, когда Chrome спросит — так вы узнаете о снижении цены

Конфиденциальность
• Список и история хранятся в chrome.storage.local на вашем компьютере
• Сеть используется только для catalog.onliner.by и catalog.api.onliner.by по отслеживаемым товарам
• Нет аккаунтов, аналитики, рекламы и продажи персональных данных

Примечания
• Проверяются только товары, которые вы сами добавили (без обхода всего каталога)
• Между запросами есть пауза (~1.5 с), нагрузка на сервис умеренная
• Цена берётся из публичного API продукта (prices.price_min), при необходимости — со страницы
```
